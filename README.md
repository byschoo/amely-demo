# Amely — demo de la web

**Web de demostración** de Amely, pastelería artesana en línea en Torrejón de Ardoz (Madrid).
No es la tienda real: Amely aún no acepta pedidos y los datos legales, precios, fotos y textos son
provisionales.

- Demo: <https://byschoo.github.io/amely-demo/>
- Este repositorio sólo contiene la web ya compilada (React 19 + Tailwind CSS 4 + Motion).
- Las fotos de tartas son ilustrativas (Unsplash) y la de la Plaza Mayor de Torrejón es de Rodelar
  (CC BY-SA 4.0). Autores, licencias y modificaciones: `media/credits.json`, el Aviso Legal de la web y
  `THIRD_PARTY_LICENSES.md`.
- La web pide a los buscadores que no la indexen (`noindex`).
